```text

工具 / 材料 / Skill 是挂载；模型看老师的话决定用不用。
问「这是什么」就解释。说「做成 Word」才交文件。
禁止：读正文猜任务 · force_agent 自动挂交付 Skill
禁止：把「本轮必须交 N 个文件」焊进 user prompt
禁止：用课件/通知/模块等词表做定向工作流
禁止厚桥四层（业主 2026-09-02 绝对禁止）：
  本地 PDF 阅读器 · 办公投影器 · 交件监工 · 硬帽截窗
  进模型前抽文/OCR/渲页 = 违法。Pico 自定 reserve 截短上游窗 = 违法。
最高：绝对禁止自己搞一套体系。绝对禁止做重体系。只允许薄适配。
```

## 1. 成功图像（本阶段）

人在公网默认入口：

1. **开放派活**（办公向复杂任务：材料、纪要后的真交付、多文件套件、可改一版…）  
2. **Agent 多步真干活**（不是单轮长文冒充）  
3. **真产物**：要文件则 **文件名可下、打开能用**；短答不硬塞  
4. **交互干净**：主窗人话、过程可理解、失败诚实、顶栏与真实结果一致  
5. **同会话可续改**（基础）  

**不要求本阶段：** Skill 架可选满、MCP、连接器、自动化大盘、教育专属终局。

## 3. 阶段规划对齐（收窄后）

### 阶段一 · ENABLE（当前 · 唯一主线）

```text
底座：Agent 稳 + 交付语义对 + 人包/下载/UI 日用
```

优先序：

1. 文档真源去毒（WHAT-IS 内撕、过期 GLOBAL PASS）——防偏航

4. UI/UX：主通道、结果区、过程区、移动可用  
5. 公网 **办公向** 复杂题人视角全优（新题，禁定向）
