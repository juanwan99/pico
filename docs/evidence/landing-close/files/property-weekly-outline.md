# 园区物业周报提纲

## 本周摘要

1. 本周整体运行平稳，无重大突发事件，报修与投诉整体可控。
2. 汇总本周工单、巡检、巡更等关键数据，与上周对比并标注异常项。
3. 提炼本周值得记录的服务亮点与待改进事项，供管理层简要浏览。

## 安全巡检

1. 完成园区周巡检全项覆盖（门禁、监控、消防通道、重点机房），逐项记录结果。
2. 对巡检中发现的隐患与违规项开立整改任务，明确责任人和完成时限。
3. 复核上一轮整改闭环情况，抽查夜间巡更与节假日值守执行记录。

## 设备维保

1. 按计划完成本周电梯、供配电、水泵、空调等设备例行维保并填写台账。
2. 处理本周设备故障/预警工单，记录故障原因、处理过程与备件耗用。
3. 汇总设备运行数据（运行时长、能耗、告警），识别需要大修或更新的设备清单。

## 住户服务

1. 统计本周住户报修、投诉、咨询工单数量及完成率，跟进未闭环事项。
2. 整理住户满意度反馈与意见渠道记录，归类共性问题并制定改进动作。
3. 更新重点住户（长期包租、高频投诉、重要客户）的服务台账与跟进状态。

## 下周计划

1. 排出下周重点巡检项与设备维保计划，明确时间与责任人。
2. 针对本周遗留待办与住户共性诉求，制定专项跟进与回访安排。
3. 规划下周例会、安全演练或满意度调研等专项工作，并设定完成节点。
