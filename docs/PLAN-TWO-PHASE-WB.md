## 2. 阶段一 · 底座可测（ENABLE）

### 2.1 目的

让 **任意** 合理复杂交付（含日后 W1–W5）在公网默认路径上：

1. 派得进去（登录 / 默认 Pi+DeepSeek）  
2. 多步做得动（过程可见，主通道不灌机审）  
3. 交得出（成功语义与顶栏一致；真 multi 仍严）  
4. 拿得到（文件名下载 + 打开能用）  
5. tip 可核、证据可远程审  

### 2.2 工作包（按序 · 可一张大卡串行）

| 包 | 内容 | 优秀出口（全要） |
|----|------|------------------|
| **P1-A** | 收口 #356：CI → 合 main → **prod-update** | `curl /api/pico/tip` = main 40 位；三行对齐 |
| **P1-B** | 公网 UI 复验 G1–G3（**非** W 终局） | 单文件交付不假红；真多文件缺份仍失败；下载打开；主气泡无工具刷屏 |
| **P1-C** | 可测性 | 稳定演示账号策略（env，密不进 Git）；E2E 脚本可登录后跑 |
| **P1-D** | 多步/产物露出基线 | 时间线或过程区可见步骤；结果区文件名一等公民不回归 |
| **P1-E** | 阶段一验收题（**载体中性**） | 3 道 **当场拟题**（1 单交付 / 1 显式多交付 / 1 闲聊）公网人视角全优；截图贴 Issue |

## 3. 阶段二 · 五题称重（MEASURE）

### 3.1 目的

用既有 **[PLAN-WB-STYLE-W1-W5](./PLAN-WB-STYLE-W1-W5.md)** 为 **唯一产品验收载体**，在公网默认路径上逐题 EXCELLENT。

### 3.2 载体（不可替换）

| 题 | 教程锚点（摘要） | 成功像 |
|----|------------------|--------|
| **W1** | 习惯打卡小程序向 | 澄清→代码/可运行前端包→修红→可体验说明 |
| **W2** | 扫榜→小说流水线 | 设定+正文+去 AI 味+续写 |
| **W3** | Skill 规格 | 可装/可贴 Skill + 触发真产物 |
| **W4** | 音乐/影像文案资产 | 歌词脚本+时间轴+可发布资产；渲片边界诚实 |
| **W5** | 脏活链 | 摘要→文档→待办→消息一条链 |

环境诚实边界见 PLAN-WB-STYLE §3（无微信工具 → Web 等价包等）。

### 3.3 执行序

```text
仅当阶段一 PASS（全优）
W1 EXCELLENT → W2 → W3 → W4 → W5
每题: 公网派活 → 多步可见 → 真产物 → 同会话修补（若教程要求）→ SELF-ACCEPT
挂: 定位通用根因修底座 → 复测该题（禁只改题词）
包末: 证据包 + 六条对照 + CLAIM-WB: NO
```

### 3.4 每题 EXCELLENT 最低线（人视角）

| 维 | 要求 |
|----|------|
| 接得住 | 开放派活，不先锁场景卡 |
| 做得完 | 多步/工具，非单轮长文冒充 |
| 交得出 | 文件可下可开或链上真产物；禁空成功 |
| 人话面 | 主窗无人审/源码墙；有文件名与用法 |
| 教程对齐 | 锚定帖的成功路径关键步不缺 |
| 诚实 | 环境做不到的写清，不装已渲染/已上架微信 |
