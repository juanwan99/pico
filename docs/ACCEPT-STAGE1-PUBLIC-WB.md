## 0. 三级评分（全局）

| 等级 | 含义 | 是否可晋级 |
|------|------|------------|
| **EXCELLENT** | 公网路径达标 + 体验不糊 + 证据可复核 | **是** |
| **PASS_WEAK** | 勉强能过但糊/不稳定/仅 API | **否 · 继续修** |
| **FAIL** | 做不到 | **否 · 继续修** |

### 一票否决（直接 FAIL 或 PASS_WEAK）

```text
- 主证据只有 loopback/API，无公网浏览器路径
- 用「你好」代替交件任务宣称条 3/4 完成
- 空成功（说已生成文件但不可下/0 字节）
- 默认 runtime 不是 pi-agent（S1.11 除外的临时调试未清）
- 密钥进 Issue
```

## 1. 小任务优秀标准（逐条）

### S1.1 公网 TLS+入口

| 项 | EXCELLENT |
|----|-----------|
| DNS | `pico.aivia.asia` → 当前设计入口 IP（edge） |
| 证书 | SAN **含** `pico.aivia.asia`；浏览器 **无** 证书警告 |
| 页面 | `/login` 稳定打开；可见登录 UI（非永久加载） |
| 否定 | 仅 `curl -k` 通、浏览器红锁 = PASS_WEAK |

### S1.2 登录进壳

| 项 | EXCELLENT |
|----|-----------|
| 登录 | 正确账号进工作台 |
| 壳 | 主输入框可用；非白屏/死加载 |
| 错密 | 失败可感知（不白静默） |
| 否定 | 登录 API 200 但 UI 进不去 = PASS_WEAK |

### S1.3 开放派活（条1）

| 项 | EXCELLENT |
|----|-----------|
| 题 | **当场**开放域交件题（非背题菜单） |
| 行为 | 直接开干，不要求先选场景卡 |
| 响应 | 有明确承接（过程或首包） |
| 否定 | 只能点场景模板才能开 = FAIL |

**推荐题干：**「写一份社区周末义工招募一页说明，生成可下载 Word」

### S1.4 多步+真产物（条3+4）

| 项 | EXCELLENT |
|----|-----------|
| 多步 | 可见过程或工具步骤（非纯一句瞎编） |
| 文件 | 可下载；体积>0；类型正确（如 OOXML `PK`） |
| 露出 | 用户在 UI 找得到下载/产物入口 |
| 否定 | 仅 ledger 有 artifact、UI 找不到 = PASS_WEAK；0 字节 = FAIL |

### S1.5 同会话改（条5）

| 项 | EXCELLENT |
|----|-----------|
| 会话 | **同一会话**第二轮 |
| 差异 | 改点出现在回复或新产物中 |
| 否定 | 新开会话假装「改」= FAIL |

**推荐改点：** 时间改周日上午；增加「雨天改室内」

### S1.6 短答纪律（条4）

| 项 | EXCELLENT |
|----|-----------|
| 题 | 「17+25，只回答数字」 |
| 答 | 得到 42（或等价）；**无**无关文件硬塞 |
| 否定 | 附带假 docx = FAIL |

### S1.7 Skill 前台（条2）

| 项 | EXCELLENT |
|----|-----------|
| 可见 | UI **≥3** Skill/能力入口 |
| 可选 | 用户点选 1 个后派活 |
| 绑定 | run/事件有 skill 痕迹 |
| 否定 | 仅后台 catalog API、UI 不可见 = PASS_WEAK |

### S1.8 过程+停止（条6）

| 项 | EXCELLENT |
|----|-----------|
| 过程 | 进行中状态用户可见 |
| 停止 | 点停止后终态 cancelled（或等价） |
| 否定 | 只能 API cancel、UI 无停止 = PASS_WEAK |

### S1.9 历史找回（条5+6）

| 项 | EXCELLENT |
|----|-----------|
| 列表 | 历史/任务可见 |
| 点回 | 能打开先前会话或任务结果 |
| 否定 | 刷新后消失且无法找回 = FAIL |

### S1.10 失败诚实

| 项 | EXCELLENT |
|----|-----------|
| 触发 | 未命中材料或故意失败路径 |
| 文案 | 中文可读；不宣称成功 |
| 否定 | 空白/英文栈直接甩用户 = PASS_WEAK |

### S1.11 方案钉死回归

| 项 | EXCELLENT |
|----|-----------|
| runtime | 默认 **pi-agent** |
| 模型 | DeepSeek 路径可用 |
| tip | 记录公网可核 tip/SHA |
| 否定 | 默默回 Kimi 默认 = FAIL |
