# 园区物业周报提纲 v2

## 本周摘要
- 汇总本周园区整体运行情况，形成一周关键指标总览
- 对比上周本周数据，标注环比变化与异常波动
- 总结本周亮点成果与需重点改进事项，明确下阶段关注方向

## 安全巡检
- 完成全园区日间与夜间安全巡检，覆盖门岗、公共区域、监控盲区
- 建立隐患登记台账，落实整改责任人与整改时限
- 对重点部位开展复查，确保隐患闭环销项

## 设备维保与能耗
- 执行例行设备维保计划，覆盖电梯、配电房、水泵房等重点设施
- 及时处理日常设备故障报修，记录维修过程与更换备件情况
- 汇总各区域能耗数据，形成能耗消耗统计与趋势分析

### 能耗优化
- 排查高耗能点位，针对照明、空调等制定错峰与节能运行方案
- 对比前后能耗数据，量化节能成效并持续优化调节策略

## 住户服务
- 汇总住户报修与咨询工单，跟进处理进度与办结情况
- 收集住户满意度反馈，归纳高频诉求形成服务改进项
- 建立重点住户服务台账，保持定期回访与沟通

## 下周计划
- 制定下周安全巡检与设备维保详细排期
- 跟进本周遗留事项与未闭环问题，明确责任人
- 部署能耗优化与住户服务专项工作，确定验收标准
