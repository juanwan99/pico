## B1 中间空态 · `B1-empty-middle-1280.png`

中间不像要说话，像产品发布页。

- 大标题「Pico，我帮你」已经占了正中，输入框里又写「今天帮你做些什么？」——两个标题抢中间。
- 标题和输入框之间塞了两排胶囊：日常办公/代码开发/设计创意，再下一排文档处理、金融服务、深度研究、视频生成、幻灯片。人还没开口，中间先是仪表盘。
- 底栏已经是一行（+ / 输入 / 上箭头），但输入框被紫线圈成里层，外面又是白胶囊，看起来仍是两层卡。
- 左栏收成图标：上头 +，下面 `...`。历史会话看不见。

## B2 底栏点开 + · `B2-plus-open-1280.png`

点 + 不是附件，是杂物抽屉。

- 弹出：Pico 快速、Pico 深度、选择工作空间、默认权限。
- 菜单盖住输入框和一排能力胶囊。人想贴文件，先看见权限和工作空间。
- 没有「上传附件」。+ 的字面意思在这页是假的。

## B3 一条对话 · `B3-one-bubble-1280.png`

发出一句短话之后，中间仍不像对话。

- 顶栏一长串芯片：`pico-fast`、方块、书签、第二个 +、分享。模型和底栏 + 重复。
- 用户气泡写成「R4R6 Evidence」名片，助手写成绿色「OpenAI」商标。中间是身份条，不是两个人在说话。
- 助手还没字，只有一个黑点。头顶又挂「当前任务 / 正在检索或作答」，右边再挂「等待模型响应 / 停止任务」。同一件事写三遍。
- 右栏空白沙箱已经撑开半屏：执行步骤、可下载文件、骨架条、「沙箱还没有打开窗口」。一句「你好」不该打开仪表盘。
- 底栏输入仍写「今天帮你做些什么？」——已经在对话里了。紫线圈还在。右侧小方块代替发送，像停录键。

## B4 中间+右（打开网页）· `B4-middle-right-sandbox-1280.png`

网页开了，中间还是空的仪表盘。

- 右边 example.com 已出来。本帧未见「来源」压顶、未见「打开文件」底栏、未见登录框（#562 这三项未回归）。
- 右栏网页只占上半，下半大片灰空。中间对话仍只有用户一句 + OpenAI 黑点，没有回复气泡。
- 顶栏 `pico-fast` + 第二套 + 还在。底栏紫线圈 + 空态文案还在。
