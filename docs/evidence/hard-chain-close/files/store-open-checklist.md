# 北区开店筹备 · 开店检查表

> 用途：开业前逐项打勾，全部通过后方可正式开门。

---

## 一、证照与合规

- [ ] 营业执照已办理并悬挂于店内显眼位置
- [ ] 食品/饮品经营许可证（如适用）已取得
- [ ] 消防验收合格证明已取得
- [ ] 卫生许可证办理完毕
- [ ] 招牌备案 / 店招审批通过
- [ ] 员工健康证齐全并留档

## 二、场地与设施

- [ ] 门店水电接通，管线验收合格
- [ ] 空调 / 新风系统运行正常
- [ ] 消防设备（灭火器、烟感、应急灯）齐全且在有效期内
- [ ] 安全出口标识清晰、通道畅通
- [ ] 地面、墙面、玻璃门清洁完成
- [ ] 标牌、灯箱、门头照明正常

## 三、设备与备货

- [ ] 收银系统安装完成并可正常出单
- [ ] 支付（微信 / 支付宝 / 刷卡）通道测试通过
- [ ] 主备货商品到货并完成入库盘点
- [ ] 易耗品（包装袋、一次性餐具、小票纸）备足
- [ ] 冷柜 / 冰柜温度达标
- [ ] 备用电源 / UPS 正常

## 四、人员与流程

- [ ] 全员到岗并完成上岗培训
- [ ] 收银与操作流程演练通过
- [ ] 交接班制度现场测试完成
- [ ] 员工着装 / 工牌统一
- [ ] 投诉与突发事件预案宣导完毕

## 五、开业保障

- [ ] 门店定位 / 地图 / 线上信息已更新
- [ ] 开业海报、摆台、花篮布置到位
- [ ] 开业礼品 / 优惠券准备齐全
- [ ] 保洁与垃圾清运安排妥当
- [ ] 全员到齐并合影记录开业时刻
