## 一、会前准备

- [ ] 确认会议时间（90 分钟）与场地 / 直播链接已公布
- [ ] 确认讲师 / 发言人角色已到位（主持人、总经理、售前、交付、QA）
- [ ] 准备《议程》`partner-agenda.md` 并分发给与会者
- [ ] 准备《FAQ》`partner-faq.md` 并提前发送预习
- [ ] 准备演示环境，验证功能可正常演示
- [ ] 确认收集参会者名单与联系方式
- [ ] 设置计时员，确保时间盒执行

---

## 二、会中执行

- [ ] 开场说明纪律与线上直播规则（10 分钟内完成）
- [ ] 每个模块在既定时间盒内完成，超时及时提示

- [ ] 未当场解答的问题登记入「待跟进清单」
- [ ] 结尾明确说明后续安排与跟进邮件预告

## 三、会后跟进

- [ ] 更新议程中需调整的事项，归档本次会议记录
- [ ] 向报名而未参会者补发资料包
