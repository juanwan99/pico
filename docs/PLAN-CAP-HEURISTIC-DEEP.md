## 2. 正确修复方向（通用）

### R1 列举结构优先（替代业务名词表抬 min）

- 主信号：顿号/逗号/「与|和|及」连接的**并列交付物枚举**、冒号后清单、编号列表  
- 领域名词表：**大幅收缩或删除考题同构词**；保留极少跨域虚词级（如「说明/清单」若保留须单测证明非题面特供）  
- 隐式包装（方案包/套件）仍可 multi，但 **min 来自结构计数**，不是广播稿∈词表  

### R2 修订绑会话产物图

- 当存在 prior artifacts 且用户表达改口/收窄/推翻上次结论 → revision  
- 字面软改口仅作弱信号；**删除**「只做低成本」「别的顺延」等题面句  
- 单测：同义改口**不同用词**仍触发；P1-B 原句不再作为唯一绿路径  

### R3 runnable 只留介质词

- html/网页/本地打开/timer 类**介质+交互**；去掉具体小游戏名依赖  

### R4 人类证据门禁

- 回归回执：HTML **必须**打开后截图或等价像素描述；文稿须「打开应用见标题正文」不只抽文本 API  
- 产品侧：verify 报告禁止把 L0 写成人类可用  

### R5 扩展名/类型诚实

- 声明 md/docx 则扩展名与 MIME 一致；未知扩展 fail-closed 或纠正
