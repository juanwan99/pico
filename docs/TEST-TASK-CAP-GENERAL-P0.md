## G6 开放回归题（示例 · 执行窗可改写但须新语义）

### N1 多产物（非 W5）

```text
请为「社区图书漂流」一次性交付三个独立可下载文件：
1) 活动规则说明
2) 志愿者排班表
3) 给居民的通知短讯合集（≥5 条）
禁止合并成一个文件四个标题。数字与日期三份一致。
```

### N2 流水线落盘（非 W2）

```text
做「竞品周观察」流水线，每阶段独立文件：
阶段1 信息源清单 → 阶段2 三条洞察 → 阶段3 一页行动建议。
然后说「把行动建议里优先级最高的改成下周再做」——须更新阶段3文件（或出版本号新文件），阶段1–2 保持可追溯。
```

### N3 可运行 + 诚实（非 W1 原文）

```text
生成一个「会议倒计时」单页 HTML（本地可打开）：输入会议名与时间，显示剩余时间。
生成后请自检：空提交、非法日期、刷新后是否还在。
若某项未实际跑通，必须写明未验证，禁止写「全部完美」。
```
