## 总则（五题共用）

| 项 | EXCELLENT |
|----|-----------|
| 默认路径 | 不改顶栏模型完成 |
| 过程 | 多步/工具或等价可见过程，非单次灌文 |
| 产物 | 可下载或可打开；非空 |
| 诚实 | 环境做不到的写边界，不装成功 |
| 假绿 | 声称可运行但验收打不开 → 整题 FAIL |

## W1 · 小工具/小程序路径（锚：宋宋教程）

| 检查项 | EXCELLENT = 教程成功等价 |
|--------|---------------------------|
| W1.1 需求澄清 | Agent 主动问清：数据存哪、1.0 范围、提醒/分类/风格等（或等价清单一次问清） |
| W1.2 出可运行物 | 代码包或可打开 Web；有项目路径/文件列表 |
| W1.3 导入/打开说明 | 逐步说明（类比导微信开发者工具）；无「你自己看着办」 |
| W1.4 红字修复环 | 同会话至少一轮：用户贴错误 → 修改 → 说明改了什么 |
| W1.5 五项自测书面 | 添加 / 状态切换 / 重进仍在 / 删除 / 空值拦截 — 逐项 PASS 或已修到 PASS |
| W1.6 分享说明 | 如何给他人试用（预览/部署/打开链接） |

**FAIL 例：** 只有 PRD；只有截图描述；修了但五项未重跑。

---

## W2 · 内容流水线（锚：Yunn 小说教程）

| 检查项 | EXCELLENT |
|--------|-----------|
| W2.1 流水线文档 | 扫榜(或模拟榜)→选标杆→拆前三章→设定候选→正文 — 步骤可复跑 |
| W2.2 拆标杆 | 写出开局钩子、金手指/核心设定、节奏、章末钩子（骨架表） |
| W2.3 设定 | ≥1 个选定设定（可有 3 候选记录） |
| W2.4 正文 | 前三章或等价长文，非大纲冒充 |
| W2.5 去 AI 味 | 检查表（模板句/感官/节奏）+ 结论 |
| W2.6 续写 | 同会话「继续写」接进度，不丢设定 |

**FAIL 例：** 直接灌一章无流水线；无拆标杆；续写另起炉灶。

---

## W3 · Skill 化（锚：Skill 生态）

| 检查项 | EXCELLENT |
|--------|-----------|
| W3.1 Skill 规格 | 触发语、步骤、输入、输出文件类型、失败条件 |
| W3.2 可复用 | 他人可按规格再跑（不依赖隐藏上下文） |
| W3.3 实测 | 用触发语跑通一次，真产物非空 |
| W3.4 一致 | 产物符合规格声明 |

**FAIL 例：** 只有聊天无规格；规格写 Word 实则只有聊天。

---

## W4 · 多模态作品包（锚：说唱/Remotion 案例）

| 检查项 | EXCELLENT |
|--------|-----------|
| W4.1 完整歌词/脚本 | 分段完整，可表演 |
| W4.2 结构时间轴 | Intro/Verse/Chorus 等时间或段落表 |
| W4.3 发布资产 | 封面文案 + 一句话介绍 + 标签建议 |
| W4.4 边界 | 未成片则明确写「未渲染」；不得暗示已有成片文件 |

**FAIL 例：** 半截歌词；谎称已生成 mp4。

---

## W5 · 脏活任务链（锚：Rion 任务链）

| 检查项 | EXCELLENT |
|--------|-----------|
| W5.1 链完整 | 同一会话：①调研备忘 ②决策一页纸 ③待办表 ④对外/对内短消息×3 |
| W5.2 咬合 | 结论与数字跨文件一致 |
| W5.3 联动改 | 改①一处关键结论 → ②或③同步更新 |
| W5.4 脏活感 | 不是一篇长文拆标题冒充四件套 — 须多文件或明确分件下载 |

**FAIL 例：** 只有①；四段同文复制；改①后②仍旧结论。
